# 参考元と採用範囲

案件管理・取り込み・納品記録のコードは独自実装です。外部リポジトリからは、役割の分け方や素材管理の考え方を参考にしています。

| 参考元 | 取り入れた考え方 | Deliveryでの実装 |
|---|---|---|
| [Immich](https://github.com/immich-app/immich) | 写真・動画を一つのライブラリにまとめて扱う素材管理 | 素材一覧から複数の完成フォルダを取り込み、同じ動画の再コピーを省き、字幕などの更新だけを反映する |
| [ClipForge](https://github.com/nyu1791-collab/ClipForge) | 完成動画・元字幕・制作記録をファイルで保管する構成 | 回収済み `manifest.json` の `rendered` 配列から完成物を読み込み、納品用ZIPへ整理する |
| [GitHub video-workflow topic](https://github.com/topics/video-workflow) | 動画案件を中心に工程と完成物をまとめる構成 | 配信者・案件・完成動画・タイトル・費用・納品状況を同じ案件画面で扱う |

Immichのソースや画面を複製したものではなく、Immichサーバーへの接続機能も追加していません。素材のまとめ方を参考に、ローカルのDeliveryで必要な機能に絞っています。

ClipForgeとの連携は完成ファイルの受け渡しです。Deliveryは制作アプリのソースコード・Python環境・モデルAPIを呼び出しません。汎用の `video.mp4` と字幕フォルダ、素材一覧にも対応するため、制作ツールとは独立して利用できます。

一括取り込みは素材のコピーと整理です。動画の内容監査、品質ゲート、追加モデル要求、再エンコードを行う工程ではありません。ファイルが見つからない場合は、その素材の未取込を表示し、取得できる残りの素材を取り込みます。
