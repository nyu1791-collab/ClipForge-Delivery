# ClipForge Delivery

配信者ごとの案件、完成動画・字幕・タイトル、費用、納品記録をまとめるローカル用アプリです。Python環境だけで単独起動し、制作済みファイルを受け取って納品用に整理します。

## 準備（Windows）

Python 3.11以降を用意し、このリポジトリをPCへ取得します。`start-windows.cmd` をダブルクリックすると、初回に仮想環境と依存ライブラリを準備して起動します。表示された `http://127.0.0.1:8765` をブラウザで開いてください。

PowerShellで手動起動する場合：

```powershell
git clone https://github.com/nyu1791-collab/ClipForge-Delivery.git
cd ClipForge-Delivery
py -3 -m venv .venv
.\.venv\Scripts\python -m pip install -r requirements.txt
.\.venv\Scripts\python app.py
```

既定の保存先は `~/.clipforge-delivery` です。変更する場合は起動前に `CLIPFORGE_DELIVERY_DATA` を指定します。DBと制作物はGitに含めません。シングルユーザー・ローカル利用向けです。

## 制作から納品まで

1. ClipForgeなどの制作アプリ側で動画を完成させ、PCへ回収する。
2. Deliveryに配信者・案件名・納期・メモを登録する。
3. `video.mp4` が入ったフォルダ、汎用の素材一覧、またはClipForgeの完成物の `manifest.json` を取り込む。
4. 動画を再生し、納品用タイトル・字幕編集版・動画ごとの納品状況を整理する。
5. 納品する動画を選んでZIPにまとめ、納品済み・納品先リンクを記録する。

ClipForgeとの受け渡しは完成ファイル経由です。DeliveryからClipForgeのPython、ソースコード、モデルAPIを呼び出しません。制作側とDeliveryはそれぞれ独立して起動・利用できます。

## 案件と完成物

案件は配信者名・案件名で検索でき、納品状況で絞れます。配信者名・案件名・納期・メモの修正、動画ごとの納品状況・メモの記録に対応します。

完成動画は案件画面で再生でき、動画・SRT・ASSを個別に保存できます。納品用タイトルの変更は、ZIP内の `titles.json` と `納品内容.txt` に反映されます。SRTの手修正版は `captions-edited.srt` として別に保存し、元字幕と一緒にZIPへ同梱します。動画に焼き込まれた字幕やASSの表示を変更する処理ではありません。

複数の動画・字幕・タイトルは「動画をまとめて取り込む」から受け取れます。同じ動画の再コピーを省き、字幕や制作記録だけが変わった場合は付随ファイルを更新します。素材の一部が存在しない場合も、取り込める残りの素材を続行します。操作と一覧形式は [素材の一括取り込みと納品](docs/HANDOFF.md) を参照してください。

## 費用と納品記録

費用は手入力で記録し、内訳を通貨ごとに合計します。費用概要と内訳は別記録です。API請求情報や残高を自動取得する機能はありません。

ZIPには選んだ動画・字幕・字幕編集版と、タイトル一覧・納品内容の案内を同梱します。Deliveryは配信者へのメッセージ送信やSNS投稿を行わず、ユーザーが納品した状況とリンクを保存します。

## データの保管

バックアップするときは取り込み処理を終えてアプリを終了し、データ保存先フォルダ全体を非公開の場所へコピーしてください。SQLiteのDB、字幕編集版、取り込んだ動画と字幕が含まれます。元フォルダのファイルは取り込み後もそのまま保管できます。

独立した役割とファイル受け渡しは [運用の整理](docs/STREAMLINING.md)、公開リポジトリから参考にした範囲は [参考元](docs/SOURCES.md) にまとめています。
